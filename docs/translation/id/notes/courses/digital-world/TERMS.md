# Digital World in Bahasa Indonesia: terms beyond KEY_TERMS.md

Two translators work on the course at the same time (Lessons 1–8 and course.json; Lessons 9–17). Read this file before choosing a term, and add to it (never overwrite). Where Indonesian schools (the *Koding dan Kecerdasan Artifisial* subject) or Komdigi (formerly Kominfo) materials have a term, it is used. "AI" stays AI.
