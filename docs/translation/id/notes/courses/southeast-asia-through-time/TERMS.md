# Southeast Asia Through Time in Bahasa Indonesia: terms beyond KEY_TERMS.md

Two translators work on the course at the same time (course.json, Lessons 1–6, the first two section checks and diagrams SAT01–SAT06; Lessons 7–12, the last two section checks and diagrams SAT07–SAT12). Read this file before choosing a term, and add to it (never overwrite). KEY_TERMS.md comes first: *bukti* (evidence), *sumber* (source), *klaim* (claim), *pengamatan* (observation), *dugaan* (inference), *konteks* (context), *sejarawan*, *Tiongkok* (China), *Benar.* / *Belum tepat.*, *Aku …* in self-checks, *kamu* for learners and *Anda* in teachers' notes.

**Conventions for the files** (L1–6): diagram notes go in `visual-SAT01.json` … beside the lesson notes, in the format of `docs/translation/id/notes/visual-L01.json` (keyed by the English label: `id`, `back`, `flag`, `note`; `desc` for the `<desc>`, which is the translated `visual.alt`). Source-card lines that start "Limit:" start "Batasan:". "Source 1:" is "Sumber 1:". Made-up examples in the checks: "This is a made-up example." is "Ini contoh rekaan."; "made-up" is *rekaan*.
