# Watch videos in Bahasa Melayu: review sheet

Made by `npm run videos:sheet` from `docs/notes/local-videos/ms.json`. Don't edit this file: edit the candidates file and run the command again.

Every lesson shows its English video, with a note that it is in English and the written version in Bahasa Melayu, until a person who speaks Bahasa Melayu watches a video below and approves it. **Nothing here is approved.** The candidates were pre-screened by an AI from YouTube's captions (in a browser that was not signed in); that is a first filter, not a review. Read docs/notes/local-language-videos.md first.

11 lessons have a recommended video, 8 videos still need someone to watch them, and 6 lessons have nothing yet.

> 
> Sumber sekunder pula ditulis kemudian, oleh orang yang mengkaji sumber primer. Contohnya buku, majalah, risalah dan akhbar.
