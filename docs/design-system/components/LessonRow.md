# LessonRow

One lesson on the course page: number, title, guiding question, time, stage dots and a Start / Continue / Review action.

Props: `number`, `title`, `question`, `time`, `status` not-started | in-progress | completed, `done`, `current`, `highlight` (the learner's next lesson, one per page), `kind` "quiz" (the section check row), `cta`, `href`, `meta`.

- Every lesson row is a link. Nothing is locked.
- Completed lessons show a check in the number disc and say "Review".
