# Chip

A pill for one-tap choices (a map site, how you practised) and dashed sentence starters that insert text.

Props: `selected`, `role` "radio" inside a radiogroup, `variant` "starter" (dashed, inserts into the writing box), `icon`, `children`.

- Selected chips fill with ink.
- Sentence starters show the blank as ___ and never replace text the learner already wrote.
