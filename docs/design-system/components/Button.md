# Button

The one button, in four variants; primary (ink) is used once per view for the thing the screen is for.

Props: `variant` primary | secondary | support | lemon | ghost, `size` md | lg, `icon` and `iconRight` (Icon names), `block`, `disabled`, `href` (renders a link), plus any button attribute.

- Label is a verb phrase in sentence case: "Continue to Write", "Read instead".
- `support` (lavender) is for help: word help, sentence starters.
- A disabled button always has a helper line nearby saying what unlocks it (see `ActionBar`).
- Keep `lg` for the main lesson action and the home call to action.
