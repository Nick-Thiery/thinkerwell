# EvidenceCard

A fictional source to study: an object, a note, a receipt, a drawing or a map; always labelled as fictional.

Props: `kind` object | note | document | receipt | drawing | map, `title`, `items` (list) or `text`, `quote` (italic), `fictional` (false only for real sources).

- Group 2–3 evidence cards in a row on laptop, one column on phones.
